# Дневник

Ежедневный дневник с серией. Только сегодняшний день, к прошлым вернуться нельзя.

## Как получить apk
1. залей проект в репозиторий на github (ветка main)
2. зайди во вкладку Actions и дождись зелёной галочки
3. apk появится в разделе Releases, уже подписанный

Локально: `gradle assembleRelease`, файл будет в `app/build/outputs/apk/release/`.

## Ключ подписи
`release.jks` и пароли в `keystore.properties`. репозиторий лучше сделать приватным.
Не теряй ключ: без него обновления поверх установленной версии не встанут.
