# Дневник

Ежедневный дневник с серией. Только сегодняшний день, к прошлым вернуться нельзя.

## Как получить apk
1. залей проект в репозиторий на github (ветка main)
2. зайди во вкладку Actions и дождись зелёной галочки
3. apk появится в разделе Releases, уже подписанный

Локально: `gradle assembleRelease`, файл будет в `app/build/outputs/apk/release/`.

## Ключ подписи
`release.jks` и пароли в `keystore.properties`. репозиторий лучше сделать приватным.
Не теряй ключ: без него обновления поверх установленной версии не встанут.

## Упражнения для лица
Тап по пункту открывает список видео. «Добавить видео» копирует ролики в память приложения (можно сразу несколько). Одно выполнение (утро или вечер) = все видео из списка, каждое по разу и досмотренное на 90% (перемотка не в счёт). Когда комплект собран, засчитывается одно выполнение, максимум два за день, и комплект обнуляется для вечернего подхода.

## Иконка и сплэш
Иконка «Рассвет»: полусолнце над горизонтом на тёмном фоне (адаптивная, плюс монохромная версия для тематических иконок Android 13+). Сплэш: то же солнце по центру на фоне темы (светлая или тёмная), без текста. Акцент приложения мягкий терракотово-розовый: `#D4705F` в светлой теме, `#F09A89` в тёмной (цвета в `Ui.kt` и `values/themes.xml`).

## Плеер
Щипок двумя пальцами: развести — безрамочный режим (видео на весь экран с обрезкой краёв), свести — обратно по размеру видео. Кнопка в углу переключает горизонтальную ориентацию. Ближе к концу ролика (за минуту, у коротких раньше) появляется плашка «Следующее видео»; тап переключает на следующее в списке, режим экрана сохраняется. Плашка показывается после зачёта текущего видео.

## Шаги
Считаются по датчику шагов телефона, нужен доступ «физическая активность». Цель выполняется сама, когда набрано 15 000. Раз в ~15 минут показание снимается и в фоне.
